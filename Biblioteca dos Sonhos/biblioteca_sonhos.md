**Biblioteca dos Sonhos**

A Biblioteca dos Sonhos é um sistema de gerenciamento de biblioteca desenvolvido em **Python**, com foco na prática de conceitos básicos de programação de forma clara e organizada. Simula situações comuns do dia a dia de uma biblioteca, ajudando a entender na prática como estruturar um sistema simples.

**Funcionalidades**:

- Cadastro de livros
- Consulta de títulos disponíveis
- Empréstimo e controle de status

**Conceitos aplicados:**

- Estruturas de decisão (if/elif/else)
- Laços de repetição (while/for)
- Manipulação de listas e strings
- Entrada e saída de dados (input/print)

**Um projeto introdutório, ideal para quem está começando em Python e quer desenvolver lógica de programação de forma prática e aplicada.**
